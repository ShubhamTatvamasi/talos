# talosctl

Check cluster health:
```bash
talosctl health
```

Check running services:
```bash
talosctl service
```

Check processes:
```bash
talosctl ps
```

list files:
```bash
talosctl ls /var/openebs/local
```

read file:
```bash
talosctl read /etc/os-release
```

Check talos dashboard:
```bash
talosctl dashboard
```
